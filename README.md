# Pet Guardian AI Web

Pet Guardian is a secure web app MVP for digital pet profiles, care coordination, medical records, role-based sharing, QR access, reminders, and partner vet access.

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Resend
- Vercel
- Cloudflare

## Project Docs
See the `docs` folder for:
- product scope
- user roles
- feature list
- screen list
- database design
- permission rules
- MVP boundaries

## Rules
- This repo is only for Pet Guardian
- Do not add secrets to GitHub
- Keep MVP scope tight
- Keep schema changes in `supabase/migrations`
