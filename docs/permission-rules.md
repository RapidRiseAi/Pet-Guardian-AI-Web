# Permission Rules

## Pet Owner
- Full access to own pets
- Can create, edit, share, and manage records
- Cannot access other owners' pets

## Vet / Clinic User
- Can view approved pet care and medical information
- Cannot access unshared pets
- No edit rights by default

## Pet Sitter / Caregiver
- Can view approved care information
- Cannot view private medical files by default
- No edit rights

## Emergency Viewer
- Read-only emergency summary access
- No edit rights
- No full profile access by default

## Admin
- Can manage platform operations
- Can view users, pets, partners, reminders, and support data
- Should not casually edit private medical data

## Super Admin
- Full platform control
- Manages admins, settings, permissions, and audit logs
