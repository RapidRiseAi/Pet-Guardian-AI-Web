# MVP Boundaries

## In Scope
- User sign up and login
- Email verification
- Owner dashboard
- Pet profile creation and editing
- Care and medical data capture
- Pet photo upload
- Document upload
- Role-based sharing
- Secure share links
- QR code generation
- Reminder creation
- Reminder email sending
- Basic vet access
- Basic caregiver access
- Emergency summary view
- Basic admin dashboard
- Audit logging for important actions

## Out of Scope
- Mobile app
- Lost pet alerts
- Adoption marketplace
- Pet sitter marketplace
- In-app payments
- Subscription billing
- Product advertising marketplace
- Advanced analytics
- Social/community features
- Chat system
- Multi-language support
